v1.3.5 - 2026-05-20
-------------------

[CHANGE] Rebrand to **A2R Toolbox** (navbar, title, PWA manifest, docs). Subtitle: troop stacking & citadel siege.
[NEW] **Toolbox mode** selector at the top: **Epic march** (troop stacking) vs **Citadel siege** (catapult walls). Stats row and unit tabs adapt to the active tool.
[NEW] **Citadel siege summary**: Summary view shows siege overview (goal, combined volley, shortfall) and per-tier catapult rows, same pattern as epic stack summary. One FAB toggles detail/summary in both modes.
[UX] Citadel **detail** cards show per-unit **volley** (`dmg · walls`); inline citadel report is a compact status alert (goal + volley), not a full per-tier list in the panel.
[UX] **Army Bonuses** live inside each unit tab (Guardsmen, Specialists, Catapults, Monsters, Mercenaries) with category-specific inputs only.
[NEW] **Global Modifiers** section added for shared strength values: **Strength against Epic %**, **Dragon included in march**, and **Dragon Strength to Army %**.
[FIX] Dragon Strength to Army can be removed from card strength when dragon is not allowed or not included in the march; this affects both Epic march and Citadel siege calculations.
[UX] Category **Army Bonuses** accordions now share open/closed preference across unit tabs, so switching categories keeps the bonuses panel behavior consistent.
[UX] Epic target presets now fill the editable layer fields; those fields are the calculation source of truth for both standard and event epics.
[UX] Card borders standardized (`app-card`); tier colors on labels and accents only, not red/white tier outlines.
[UX] Layout alignment tightened: removed unnecessary Bootstrap row gutters from non-grid sections so cards, accordions, and unit rows stay inside the main container.
[UX] Checkbox selection no longer lifts tier cards vertically; selected cards keep a subtle shadow without layout jitter.
[UX] Help modal widened on desktop (`modal-xl`) for a more comfortable guide/readme layout.
[UX] Epic/Citadel mode icons refreshed with Game Icons; Detail/Summary headings now use consistent view icons across both tools.
[UX] Mercenaries tab: WIP alert — army bonus inputs are hidden; mercenary damage ignores bonus % until data is ready.
[NEW] Presets and share codes (**v4**) save **Epic march vs Citadel siege** mode and **citadel wall count**; v1–v3 codes still import (defaults: epic mode, no wall goal).
[UX] Loading a preset always opens **Summary** view for epic and citadel setups.
[FIX] Mode switching keeps the selected Detail/Summary view, switches Citadel to Catapults, and returns Epic mode to Guards.
[CHANGE] Citadel siege panel and help copy trimmed (removed wall reference line, redundant helper text, and stale preset wording).
[REFACTOR] Citadel reports, bonus blocks, and summary stat rows use HTML `<template>` clones (`dom.js`) instead of string-built markup in JS.
[PWA] Service worker precache updated for new shared JS and icon assets.
[PWA] Install prompt banner added: browsers that support install show a dismissible **Install app** prompt and hide it after install or dismissal.

v0.10.0 - 2026-05-13
-------------------
[NEW] Preset bar reset: One control clears stat inputs, deselects all units, and returns the preset dropdown to no selection (saved presets are untouched).
[NEW] Army Presets: Save and load army compositions to localStorage for quick recall.
[NEW] Preset Management: Save, overwrite, rename, and delete named presets from a compact bar (dropdown + Reset + Save + Delete + Export + Import).
[NEW] Preset Export: Share codes for the currently selected preset only (`a2r-preset:` + base64url JSON with version, display name, stats, and unit ids). Export is disabled until a real preset is selected. Successful export copies to the clipboard; if the Clipboard API is unavailable, a modal shows the code for manual copy.
[NEW] Preset Import: Modal with a paste area; Import stays disabled until the field is non-empty. Decodes and validates share codes (length limit, version check, numeric stats, unit ids that exist in the DOM). Saves as `Imported: <original name>` with `(2)`, `(3)`, … on name collisions, then loads the new preset after the modal closes.
[UX] Instant load: Choosing a preset in the dropdown applies it without a separate Load button.
[UX] Auto-Summary: Loading a preset switches to Summary View for instant review.
[UX] Preset modal: Bootstrap modal for save, overwrite confirmation, and delete (replaces alert/prompt/confirm).
[UX] Save validation: OK stays disabled until the preset name field has text; "Update" checkbox controls in-place edit vs new name behavior.
[UX] Preset bar actions: Export uses outline-info and Import outline-success so they read separately from Save (primary) and Delete (danger).
[FIX] Modal sequencing: Overwrite confirmation opens only after the save modal has fully hidden, avoiding missing dialogs when chaining modals.
[FIX] Save preset disabled until input: The Save button stays disabled until at least one of Leadership, Authority, or Dominance has non-whitespace text, including on load and after loading a preset from the dropdown (avoids saving with no stat context).
